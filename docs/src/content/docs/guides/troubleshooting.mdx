Start every investigation by running `zerovdd doctor` from an **elevated Administrator** prompt so it can inspect both `\ZeroVddControl` and `WUDFHost.exe` loaded modules:

```powershell
zerovdd doctor
zerovdd doctor --json
```

## Capturing Driver ETW Traces

`zerovdd.dll` logs non-blocking TraceLogging events under provider `ZeroVdd.Driver` (`{06714745-69DC-41FF-9684-C532D5183A74}`). Capture a 10-second trace from an elevated prompt:

```powershell
zerovdd doctor --capture-etw 10
```

This writes `%TEMP%\zerovdd-driver.etl`, inspectable in Windows Performance Analyzer (WPA) or via `tracerpt`. See [Doctor and ETW Reference](/reference/doctor-and-etw/).

## Common Issues & Fixes

### 1. `ERROR_ACCESS_DENIED` Opening `\ZeroVddControl`

- **Symptom:** `zerovdd doctor` reports `control_device.state = "access_denied"`, or `zerovdd display add ... --hold` fails with access denied.
- **Cause:** `\ZeroVddControl` enforces a `SYSTEM` + `Administrators` check in `EvtDeviceFileCreate`. Non-elevated callers are denied direct Control Device handles by design (while DWM, DXGI, and games continue accessing the `Class=Display` adapter normally).
- **Fix:**
  - Ensure `zerovdd-svc` is running (`sc query zerovdd-svc`). When running, `zerovdd display`, `zerovdd sunshine`, and `zerovdd-tray.exe` route through `\\.\pipe\zerovdd-svc` without elevation.
  - Or run standalone `--hold` / `--lease` and full `zerovdd doctor` checks from an elevated Administrator prompt.

### 2. Driver Not Loaded, Code `31`, or GPU Reset (TDR)

- **Symptom:** `control_device.state = "not_installed"`, no `WUDFHost.exe` shows `zerovdd.dll=true`, or Device Manager displays Code `31`, `43`, or `52`.
- **Checks:**
  1. Run `zerovdd doctor` elevated (non-elevated `CreateToolhelp32Snapshot` cannot inspect `WUDFHost.exe` modules).
  2. Run `zerovdd setup status` to confirm an `oem*.inf` and `Root\ZeroVdd` node exist with `problem=0`.
  3. **Code `31` (`0x80070241` / `CodeIntegrity` Event `3004`):** Occurs when loading a self-signed local build while Memory Integrity (HVCI) is ON and `testsigning` is OFF. Enable `bcdedit /set testsigning on` on a test host or install a SignPath / Partner Center signed release.
  4. **After GPU reset (`Win+Ctrl+Shift+B`) or TDR:** Check `last_gpu_switch_failed` in `zerovdd doctor`. If `true`, run `zerovdd display switch-gpu auto` and verify `[gpu]` in `config.toml`.

### 3. Washed-Out HDR or ACM Flipping on Physical Monitors

- **Symptom:** Virtual display looks washed out, HDR flips Auto Color Management (ACM) instead of HDR, or physical monitor ACM changes after a stream.
- **Checks:**
  1. Confirm `OS HDR/ACM profile` in `zerovdd doctor` shows `Win11 24H2+ (split HDR/ACM ...)` on builds `>= 26100`.
  2. Confirm `dd_configuration_option = disabled` is set in `sunshine.conf` (via `zerovdd sunshine configure --apply`) so Sunshine's older switcher does not race with ZeroVDD.
  3. Confirm `--hdr` (CLI) or `SUNSHINE_CLIENT_HDR=true` (Sunshine) was sent and `hdr_capable: true` appears in `zerovdd doctor`.

### 4. Pinned `output_name` or Black Screen in Sunshine

- **Symptom:** `zerovdd sunshine configure` warns that `sunshine.conf` pins `output_name = ...`, or Moonlight connects to a black screen in `isolate` mode.
- **Fix:** Clear the pinned display and restart Sunshine:

  ```powershell
  zerovdd sunshine configure --apply --clear-output-name
  ```

  If the host has zero physical monitors connected, enable `headless_standby = true`. See [Headless Hosts](/guides/headless-hosts/).

### 5. Stale `%ProgramData%\zerovdd\topology-backup.json`

- **Symptom:** Physical monitors did not restore after a hard power loss, or `zerovdd sunshine status` reports `backup_present=true` when idle.
- **Fix:**
  1. Run `zerovdd display restore` (or `zerovdd sunshine stop --force`).
  2. If you already rearranged monitors manually in Windows Display Settings and do **not** want the old backup re-applied:

     ```powershell
     Stop-Service zerovdd-svc
     Remove-Item "$env:ProgramData\zerovdd\topology-backup.json" -Force
     Start-Service zerovdd-svc
     ```
